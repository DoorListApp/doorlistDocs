---
title: "Duplicate an Event List"
description: "How to create a new event using the same guest list as a previous event."
---

1. Go to the **Calendar** tab.
2. Tap the event to open the event admin page
3. Tap the **⋮ (three dots)** menu in the top-right corner.
4. Select **Duplicate Event**. 
5. Enter a new name and start time for your event. 
6. Tap **Duplicate **to publish. 

<Info>
  **Tip:** Instead of duplicating the event, you can also invite previous guest lists directly.
</Info>
