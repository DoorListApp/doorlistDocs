---
title: "Create a Group"
description: "Learn how to create a group on DoorList"
---

## Method 1

1. Tap the Blue + Icon in the middle of the dock
2. Tap **Create Group**
3. Enter your group name,
4. Add a description (_optional)_
5. Select a School
6. Choose **Must Request To Join**
   1. **ON**: Members must be added directly or request to join.
   2. **OFF**: Members can be added directly or join freely.

## Method 2

1. From the **Home** tab, select **Add a Group**.
2. Tap **New Group**.
3. Enter your group name. 
4. Add a description (_optional)_
5. Select a School
6. Choose **Must Request To Join**(same options as above). 

_If you are the first group at your school, you will need to create a new school_
