---
title: "Manage Event Capacity"
description: "How to set, remove, and alter event capacity on DoorList"
---

Setting a capacity limits how many guests can add themselves to an event via join code or link. Hosts can still manually add guests beyond the set capacity.

## Set Event Capacity

1. Open the event tile (from the **Home** or **Calendar** tab).
2. Tap the **⋮ (three dots)** in the top-right corner.
3. Select **Edit Event**.
4. Scroll to **Guest List**.
5. Toggle on **Enforce Max Event Capacity** and set the number.

## Remove Event Capacity

1. Open the event tile (from the **Home** or **Calendar** tab).
2. Tap the **⋮ (three dots)** in the top-right corner.
3. Select **Edit Event**.
4. Scroll to **Guest List**.
5. Toggle off **Enforce Max Event Capacity**.
