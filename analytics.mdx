## Analytics

You can find Analytics for any event in the event page.

1. **Attendance Rate** – The percentage of invited guests who attended.
2. **Check-In Methods** – How attendees checked in (scan, location, website, manual).
3. **Scan Attempts** – How many people attempted to scan into the event.
4. **Total Invites** – A summary of all invites and RSVPs.

<Warning>
  Guests must check in via scan, location-based check-in, website attendance, or manual check-in to be officially marked as _Attended_.
</Warning>

**Export Event Report** – Hosts can export an `.xlsx` file with detailed data, including scan history, check-in times, invite methods, and more.

## Attendance

**Tip:** Use location-based check-in or website attendance if you want to track attendance without using a scanner. Learn more in **Check-In Options** (under Advanced Settings).
